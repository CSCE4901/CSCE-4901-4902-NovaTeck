# Curated learning resources

Verified October 24, 2026 using the official pages and official search results. These are starting points, not claims that one resource covers every requirement in a broad field. Provider software, cloud usage, certificates, or optional exercises may have separate costs; no paid access is required simply to view the linked guides. No top-30 skill was skipped for an unconfirmed link. The initial Jira overview URL was replaced with the confirmed Atlassian Support guide.

Selection: the 30 most frequent required skills across active job listings, counted by distinct job ID. Counts below are an audit snapshot, not a live counter and are not embedded in the app. Existing gap-response demand counts are used in cards when available. Otherwise the demand line is omitted. No API requests or endpoints were changed.
