# NovaTeck

NovaTeck helps students explore technology jobs in the Dallas–Fort Worth area and compare their skills with job requirements.

## Features

- Search and filter job listings.
- Manage a profile and skills.
- Scan PDF or DOCX resumes to identify skills.
- Compare skills with a target job and view market insights.
- Review flagged skills through an administrator dashboard.

## Built with

React, Python (Flask), and MySQL.
